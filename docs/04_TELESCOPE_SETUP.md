# Telescope (Brave Search API) セットアップガイド

## Telescope機能の概要
Telescope（WebTelescope）機能は、ARK（本システム）が自律的なインターネット検索を行うための重要なツールです。
AIモデルの事前学習データには含まれていない最新ライブラリの仕様調査や、未知のバグ・エラーコードの解決策などを「外界の知識」として取得するために不可欠な機能です。

本プロジェクトでは、高精度かつ無料枠で利用できる「**Brave Search API**」を採用しています。

## アカウント作成とAPIキー取得手順

1. **公式サイトへアクセス**
   [Brave Search API 公式サイト](https://brave.com/search/api/) へアクセスしてください。

2. **アカウント作成（サインアップ）**
   - 画面の「Get API Key」や「Sign Up」などのボタンからサインアップ画面へ進みます。
   - メールアドレス等を入力して、開発者用のアカウントを作成します。

3. **プランの選択とAPIキー生成**
   - アカウント作成・ログイン後のダッシュボードにて、利用プランを選択します。
   - 必ず **「Free Data tier（月2,000回まで無料）」** のプランを選択してください。
   - プラン選択後、ダッシュボードからAPIキー生成（Generate API Key等）を行い、表示された文字列をコピーします。

4. **環境変数の設定**
   - プロジェクトルートにある `.env` ファイルを開きます。
   - コピーしたAPIキーを `BRAVE_SEARCH_API_KEY` の値として設定します。

   ```env
   BRAVE_SEARCH_API_KEY="ここにコピーしたAPIキーを貼り付け"
   ```

## 🛡️ 新規メンバーの皆様へ: 安心感を与える補足

ARKのプロジェクトでは、新規参画者の方が費用面での不安を感じずに開発に没頭できるよう、**完全な安全設計（お財布防衛リミッター）**を組み込んでいます。
安心してこちらの機能を有効化してください

- **無料枠で十分稼働（クレジットカード請求なし）**
  サブスクリプションで「Free Data tier」を選択した場合は、無料でクレジットカード等の不正な課金も行われません（登録フローで求められた場合も決済は発生しません）。

- **消費を抑えるシステムリミッター設計**
  `src/tools/telescope.py` の内部には `self.MAX_CALLS_PER_RUN = 3` という制限ルールが組み込まれており、1回の実行で消費するAPIコール上限が3回までに制限されています。
  そのため、「ARKが暴走して、いつの間にか月2,000回の無料枠を使い切ってしまった…」という事故は起こらない設計になっています。

- **通信を完全に遮断するモックモードも搭載**
  「API制限が気になる」「オフラインで開発したい」という場合のために、通信自体を遮断する機能もあります。環境変数で `ARK_MOCK_MODE=1` を指定すると、本物のAPIを一切叩かず、内部のテストデータを返す「モックモード」に切り替わります。
